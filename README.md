# Self Care Vision Board 2027

36 self-care goals for 2027 in 6 groups (rest and sleep, body, mind, boundaries, joy, people). Each goal has why it matters and a first step for this week, plus 12 questions and a 45-minute plan.

**Live page:** https://pittner.github.io/self-care-vision-board/

- Press a goal and it opens in the [free vision board maker](https://visionboard.bemooore.com/free-vision-board-maker/?mode=wallpaper&layout=text&utm_source=github_readme&utm_medium=referral&utm_campaign=selfcare_2027) with the first step under it; save it as a 1080x1920 lock screen and see it every day
- Or type your own goal and first step
- No signup, nothing uploaded, MIT licensed

Rebuild: `python3 build.py` (no dependencies)
